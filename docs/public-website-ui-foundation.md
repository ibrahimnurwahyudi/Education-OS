# Public Website UI Foundation

Education OS public website is implemented as a custom React/Vite experience using UX patterns inspired by the MIT-licensed Launch UI component/template ecosystem.

Reference:
- Launch UI: https://github.com/launch-ui/launch-ui
- License: MIT

We do not import the Education OS application workspace from the template. The public website remains a dedicated marketing/product surface and the authenticated/trial Education OS workspace remains at /app/.

Adaptation principles:
- mobile-first responsive navigation
- clear primary/secondary CTAs
- role-based journeys
- progressive disclosure for complex product architecture
- visible keyboard focus states
- reduced-motion support
- accessible touch targets
- semantic SEO metadata

Education OS-specific content, information architecture, branding, product claims, and workspace behavior remain original to this repository.
