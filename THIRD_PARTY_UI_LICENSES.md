# Third-party UI references

Education OS public website UX is independently implemented for this project and adapts interaction/layout ideas from MIT-licensed open-source projects:

- Launch UI — https://github.com/launch-ui/launch-ui — MIT License.
- shadcn/ui — https://github.com/shadcn-ui/ui — MIT License.

No third-party brand identity, product copy, or proprietary assets are used as the Education OS product identity. Education OS maintains its own information architecture, copy, visual tokens, domain workflows, and application logic.

When redistributing substantial portions of third-party source code, retain the applicable copyright and MIT license notice from the original project.
